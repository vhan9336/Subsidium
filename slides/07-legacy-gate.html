The legacy gate

The old approach, shown on the same readings so you can compare.

  • It follows inertial and accepts a rangefinder reading only if it is close to that.
  • After several rejections in a row, it declares the rangefinder failed and never listens to it again.
  • If inertial is the one that drifted, or the ground really changed, the correct rangefinder gets thrown out.
  • It has no third sensor to check against, so it cannot tell the difference.
